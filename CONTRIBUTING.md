# Contributing

Thank you for contributing to the Enterprise Agentic SDLC Framework.

## Before starting

1. Read [AGENTS.md](AGENTS.md).
2. Confirm the proposed work aligns with the [roadmap](ROADMAP.md) or an approved issue.
3. Ensure the work meets the [Definition of Ready](standards/definition-of-ready.md).
4. For architectural or governance changes, obtain maintainer approval before implementation.

## Development process

1. Create a focused branch from the current default branch.
2. Follow the [feature development playbook](playbooks/feature-development.md).
3. Keep commits scoped and use clear, imperative commit messages.
4. Add tests or validation evidence appropriate to the change.
5. Update authoritative documentation without copying policy across files.
6. Open a pull request using the repository template.

## Pull request expectations

A pull request must explain the problem, scope, risk classification, validation, and human decisions required. It must satisfy the [Definition of Done](standards/definition-of-done.md) before merge.
